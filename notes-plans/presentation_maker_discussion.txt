AI Presentation Generator - Technical Design Report (MVP)
Project Goal

Transform the current Next.js presentation into an AI-assisted presentation generation platform.

The AI is not responsible for designing presentations. Instead, it generates content for predefined slide templates using a structured knowledge base and client requirements.

The presentation itself remains deterministic and fully controlled by the React application.

Final Technical Principles
1. AI generates content, not presentations.
2. React owns all layouts and templates.
3. Knowledge lives in one structured JSON file.
4. Separate recommendation from content generation.
5. Humans approve recommendations before generation.
6. AI communicates only through structured JSON.
7. Use local models (Ollama + Qwen) for MVP to avoid API costs.
8. Keep the Python service lightweight—plain FastAPI functions instead of agent frameworks.
9. Treat the AI service as replaceable; switching from Ollama to Gemini or another provider should require minimal changes.
10. Build the end-to-end workflow first, then improve the intelligence incrementally.
